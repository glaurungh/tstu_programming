## Лабораторная работа 2

Кэш на основе алгоритма 2Q
Алгоритм 2Q (Two Queues) - это улучшенная версия классического алгоритма LRU (Least Recently Used). 
Основная цель алгоритма 2Q - предотвратить вытеснение часто используемых данных при сканировании или добавлении большого количества новых элементов, к которым больше не будет обращений.

## Лабораторная работа 3

Утилита для конвертации простых ini‑подобных конфигураций в JSON с автоматическим приведением типов.
Формат входного файла:
Поддерживается простой ini‑стиль без секций:
Одна пара ключ = значение на строку.
Знак = может окружаться пробелами (key=value, key = value и тд).
Строки, начинающиеся с #, считаются комментариями и игнорируются.
Пустые строки также игнорируются.
