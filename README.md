## Лабораторная работа 2

Кэш на основе алгоритма 2Q
Алгоритм 2Q (Two Queues) - это улучшенная версия классического алгоритма LRU (Least Recently Used). 
Основная цель алгоритма 2Q - предотвратить вытеснение часто используемых данных при сканировании или добавлении большого количества новых элементов, к которым больше не будет обращений.
